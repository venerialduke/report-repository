Publish a report in 4 steps

Reports are plain HTML files in this repo. Merging to main publishes them.

1 · Scaffold

Create the folder from the starter template.

npm run new -- my-report-id \
  --title "Headline that states the finding" \
  --area "Marketing" \
  --owner "Lena Kowalski <lena.kowalski@parcelandpine.com>"

2 · Write

Edit reports/<id>/index.html using the brand classes and chart JSON. Fill in report.json: area, topics, tags, owners, key findings, code links.

3 · Check

Validate the metadata and chart JSON, rebuild the catalogue, then preview locally.

npm run check
npm run serve   # http://localhost:8000

4 · Review & merge

Open a pull request. CI validates it, a teammate reviews the story and charts (the Claude skills below help), and merging deploys it to the hub.
